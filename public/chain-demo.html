A navigation graph, as data

The views are built imperatively — new Wrapper(), new Text() — and the graph between them is one { op: "morph" } node that names them by id. The node never holds a component; it holds ids, so it stays serialisable data while the views keep the full expressive surface of the classes.

home ──Work──▶ work ──Aurora──▶ aurora ──Contact──▶ contact
  └──Contact──────────────────────────────▶ contact
