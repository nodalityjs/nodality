## `video` learned the shape every landing page actually uses

`video` accepted six options: `id`, `opacity`, `radius`, `type`, `url`, `width`.
A muted background loop — the most common video on a marketing site — could not
be written at all. It now takes **23**, and the loop shape is data:

```js
{ type: "video", id: "shell-loop", url: "/loops/shell.mp4",
  sources: [{ url: "/loops/shell.webm" }, { url: "/loops/shell.mp4" }],
  poster: "/loops/shell.jpg", preload: "metadata",
  autoplay: true, loop: true, controls: false, decorative: true,
  aspectRatio: "3 / 2", objectFit: "cover" }
```

Three things happen without being asked for, because each is a mistake that is
easy to make and invisible when made:

- **`autoplay` implies `muted` and `playsinline`.** Browsers block an unmuted
  autoplay and the clip simply never starts. `muted: false` still overrides.
- **An autoplaying clip pauses off screen and in a hidden tab**, and resumes.
  Decoding frames nobody is looking at is the most expensive thing an ambient
  loop can do.
- **`prefers-reduced-motion: reduce` cancels autoplay** and leaves the poster.

`sources` become `<source>` children with the MIME type inferred from the
extension; the `src` attribute is removed when they are present, since it would
otherwise win and quietly defeat the whole list.

`new Video(url)` is unchanged: still a player, still with controls.

## `gridOverlay` — a new element type

A blueprint grid drawn over the page: lines, registration marks at the
intersections, and small readouts beside chosen ones.

```js
{ type: "gridOverlay", id: "grid", columns: 4, rows: 2, inset: 16,
  readouts: [{ id: "part", col: 1, row: 1, text: "horná časť · 412 mm" }],
  mobile: { columns: 1, rows: 4 } }
```

Decoration by contract: `aria-hidden`, `pointer-events: none`, nothing
focusable. Lines are drawn with `currentColor`, so `color` recolours the whole
grid and Theme applies without extra work. A mobile grid replaces the desktop
one below a breakpoint, and labels that would fall outside the box flip inward
rather than being clipped.

The option is `columns`, not `cols`: the shared `cols` means
`grid-template-columns` verbatim, and one name cannot mean two things.
