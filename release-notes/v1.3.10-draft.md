## Fix: `video` dropped `id`

`{ type: "video", id: "shell-loop", … }` rendered a clip with no `id` attribute.
Nothing failed and nothing was reported — the element simply could not be named,
so a node could not target it:

```js
{ op: "duotone", target: ["shell-loop"] }   // matched nothing
```

The parameter was listed in `npx nodality schema video` and forwarded by the
mapper the whole time; only the component never applied it. Found while placing
an ambient loop in a page grid, where the id vanished between the spec and the
DOM.

Covered by a test, alongside the loop behaviour added in 1.3.9.
