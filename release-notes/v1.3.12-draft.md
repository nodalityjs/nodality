# v1.3.12 — draft

> Draft only. Edit freely and paste into the GitHub release; nothing here is published.

## A correction to 1.3.11

1.3.11 said every element type applies its `id`. **That was true of the instance
the mapper builds, and false of the page.** Des does not mount that instance; it
runs the instance's generated code, and composites embed their children's code
inside their own. Rendered the way a page renders, 17 of 36 types still arrived
without their id — `button`, `table`, `nav`, `sideNav`, `circle`, `polygon`,
`code`, `stack`, `radio` and others. The test that claimed otherwise was checking
the wrong object.

## Every element type now renders its `id` — through Des

- The base class applies `obj.id` after whatever `set()` a subclass defines, so a
  component cannot forget it; the id is written on every run of the generated
  code, which is the run that reaches the page.
- The mapper writes the element's id into the options `toCode()` serialises, and
  it **wins** over a hardcoded one: `free` emitted `id: "#3"` for every free
  element on a page.
- The components that emit their own code carry it too: `Switcher` (nav, sideNav,
  multiswitcher), `Stack` (whose code was a hardcoded `set({})`), `SideNav`
  (configured through `setup()`, not `set()`), `AreaSwitcher` (whose node is not
  `res`) and `RadioGroup` (not an Animator).
- The test now renders every type through Des and looks in the resulting DOM,
  including an element nested two composites deep.

## Fixes

- **`img` with `resprop` blanked the whole page.** Image passed the breakpoints
  to `resprop()` without its options, which stored `undefined` as the
  component's options; its generated code then threw during hydration and the
  mount was left empty. `validate_nodes` accepted the spec and prerender — at a
  phone's width — passed. `code` and `wrap` made the same call. `resprop()` no
  longer lets a one-argument call wipe a component's options, and a new test
  renders every type that reads `resprop`, at desktop width, with it set.

- **`audio` rendered nothing and threw.** It had no `toCode()`, so Des
  interpolated the instance and emitted `[object Object].render(...)`.
- **A transform node without `values` crashed a page seconds after load**, inside
  a timer, as an uncaught exception far from its cause. It is now ignored with a
  warning, like any other unrecognised transform descriptor.
- **Links ignored `font` and `pad`.** The mapper overwrote them with Arial and
  10px, so a nav could never match the page's typography.
- **`button` ignored a bare-number `radius`** — `radius: 999` did nothing.
