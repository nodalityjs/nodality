## What an agent hit building a real site, fixed

Every item below came from building the Suitcase N°01 site through Nodality's
agentic tooling — the skill, the MCP server and the validator — and writing
down where they let the agent down.

### validate_nodes warns on parameters a type lists and ignores

The conformance test has long kept a baseline of parameters a type advertises
and does nothing with — `size` on a `p`, `color` on a `checkbox`. The test knew;
the validator told the author the page was fine. The baseline now lives in the
library (`lib/known-inert.js`), the test reads it from there, and
`validate_nodes` reports each use as **`PARAM_INERT`**, with a hint for what to
use instead (`tag` and `keySet` for a heading's size).

### get_schema puts a type's own parameters first

Each parameter now says where it is read: `via: "mapper"` (the type reads it by
name) or `via: "component"` (only reachable through a component the element is
forwarded to). `get_schema <type>` lists the type's own parameters first, then
described ones, then the rest, and adds a summary — `nav`: 42 read by the type
of 173. They used to be alphabetised together.

### preview says when something rendered nothing

`preview` takes a `viewport` (`"phone"`, the default, or `"desktop"`) and lists
ids that rendered **`empty`**. A nav previewed as a 181-byte empty box with no
explanation; now the report says which element and why that can happen.

### MCP registered where sessions start

`npx nodality mcp --register [--root=<dir>]` writes the server into
`<dir>/.mcp.json`. From a folder above the project the entry runs
`npx --prefix <project> nodality mcp`, so it is still the project's installed
version that answers. Sessions opened one folder up never saw the project's own
`.mcp.json` before.

### link-local: test an unreleased library in a real site

`npx nodality link-local --from=<repo>` builds a local checkout and copies it
into the project's `node_modules`, leaving a marker; every other `nodality`
command then warns that the project runs a local build, and when it was built.
`--undo` reinstalls the release from the lockfile. It replaces a manual copy
that nothing reported once done.

### check_page reads contrast the way people do

`check_page` keeps its WCAG check and adds **`FAINT_TEXT`**: text under 24px
that passes WCAG but falls below APCA Lc 75 (under 16px) or 60 (larger), a
little less for weight 600+. A thin 13.8px mono on a mid-tone turquoise passed
WCAG at 11:1 and read faint to its reader; APCA put it at Lc 72.

### Fixes

- **`form.title`** is now the form's accessible name (`aria-label`). The agent
  surface already used it as its tool's description, so the schema called it
  ignored by the form. Form code generation now escapes string values — a title
  containing a quote generated code that did not parse.
- **No more `round()` deprecation errors from the library itself.** `input`
  (text fields) and `a` called the deprecated method internally, so every page
  with a field logged an error it could not fix. `rounded: true` on a link now
  actually rounds (0.5rem); it had set `border-radius: undefined`.
