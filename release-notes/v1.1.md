# Nodality 1.1 – transitions become nodes

**14–17 August 2026 · 1.1.0 → 1.1.15**

The 1.0 line made a page's *appearance* data. 1.1 does the same for the
one thing that had stayed outside the two arrays: what happens when a
user acts. A transition is now an ordinary member of `N`, and by the end
of the line a whole navigation graph is one node.

```js
{ op: "morph", effect: "t-vhs", duration: 620, back: true,
  chain: [
    { from: "home",   to: { Work: "work", Contact: "contact" } },
    { from: "work",   to: { Aurora: "aurora" },  effect: "t-split" },
    { from: "aurora", to: { Contact: "contact" }, effect: "t-bloom" },
  ] }
```

Before this, a page wanting a morph captured both sides itself, measured
two rects, drove a timeline and wired the clicks – a few hundred lines
sitting *around* the arrays rather than in them.

## Highlights

**A transition is one node.** `{ op: "morph", from, to }` names a source
element and a mapping from interaction labels to destinations. The
mapping is keyed by label rather than position on purpose: a responsive
navbar renders a different set of links at different breakpoints, so the
*n*-th link is not the same link at two window widths.

**A chain is a navigation graph.** Carry `chain` and the same node
describes a whole traversal. The entries are **edges, not keyframes** –
entry two is reachable *from* the state entry one lands on, so a landed
state becomes a source. Settings on the node are defaults each edge may
override. `back` is history: it unwinds the path actually taken, not the
edge list, which is what every browser has already taught your users.

**The interface stays operable while it is being transformed.** Pointer
input is inverted through the compiled shader, and hit testing is
reconstructed for content the browser hosts inside a canvas and refuses
to hit-test. A morph that looked right but ignored every click is the
failure this line spent most of its effort removing.

**Agents can write nodes without guessing.** `nodality mcp` serves the
two-array API over the Model Context Protocol – the op registry as data,
a validator that returns did-you-mean suggestions, and a preview that
renders a pair to a file. Zero dependencies: the JSON-RPC framing is
hand-rolled rather than taking the SDK.

**Ids may be written either way.** `"work"` and `"#work"` name the same
element, in every node and at every level of a chain.

## Added

- `{ op: "morph" }` – transitions as nodes, with `effect`, `duration`,
  `back`, `live` and `fade`, and per-side art direction via
  `side: "old" | "new"`.
- `chain: [...]` – a morph node as a navigation graph, with per-edge
  overrides and history-based `back`.
- `nodality mcp` – the MCP server; `nodality/validate` exposing
  `validateNodes(nodes, elements)` and `describeOps()`.
- Pointer retargeting into canvas-hosted content, so a transformed
  surface remains clickable.

## Fixed

The bugs worth naming, because each was silent:

- **`new Image()` returned a component, not an image.** The package
  exports a component called `Image`, and the standard way to consume it
  overwrites the DOM constructor – so `onload` never fired, the promise
  never settled, and the morph hung forever with no error and no canvas.
  Both capture paths now use `document.createElement("img")`.
- **The ESM bundle shadowed browser globals.** It ended with
  `export const Image=…`, `Text` and `Range`; a consumer's bundler
  concatenated the module and the renames leaked.
- **A live morph never handed the source back at `t = 0`.** The canvas
  stood down only when it hosted no content – right at the end of a
  morph, wrong at the start – so the source stayed `display: none` and
  what remained on screen was the shader's frozen first frame.
- **A state returned to came back invisible but selectable.** Ink
  suppression was restored only at `t = 1`; a chain returns to states
  that live inside the raster host, where `t = 0` is the endpoint.
- **The validator lagged the runtime.** It accepted `"#home"` while the
  runtime resolved only `"home"`, and it rejected the `chain` form
  outright – telling an agent the documented API was invalid and the
  broken node was fine. Both corrected, and a typo inside a chain edge
  now reports at that edge's own path.
- **A morph parameter typo was silent.** `duraton: 900` produced a
  transition at the default speed and reported nothing.

## Notes

The live (HTML-in-Canvas) capture backend is **experimental and
flag-gated**: available in Chromium behind `CanvasDrawElement`, absent in
released browsers by default. Where it is missing the pipeline falls back
to snapshot on its own, so a page authored against it degrades to stills
rather than breaking. Determinism claims cover the compiled artefact, not
the pixels a GPU produces.

1.1.2, 1.1.3 and 1.1.6 were tagged during release iteration; 1.1.2 and
1.1.3 never reached npm, and 1.1.6 is identical to 1.1.5 apart from its
version banner.
