## A product's loading state keeps the product's layout

Until Shopify's data arrives, a `product` shows its static children in the
placeholder Shopify provides — the same copy the prerenderer writes into the
HTML. That placeholder was a plain block, so the static children lost the
product's own layout: no grid, no gap. On a phone the static price and options,
which are inline text, ran into one line ("From €3,900Size: Cabin · …") until
the live elements replaced them.

- The placeholder now has no box of its own (`display: contents`): its
  children lay out as the product's, in its grid or flex and with its gap,
  exactly where the live children land — no jump when Shopify renders.
- Shopify still hides it once data arrives: its rule is
  `[shopify-loading-placeholder][hidden] { display: none !important }`, which an
  inline value cannot override.
- Covered by a unit test through Des, which fails without the fix.
