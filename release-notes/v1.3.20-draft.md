## `check_page` without the MCP server

`check_page` was reachable only as an MCP tool. Project MCP servers need
approving per project, and in a session where the server was not loaded an
agent could not run it at all: the module was not exported and no command
reached it. Now:

- `npx nodality check <page.html>... [--base=<url>]` — prints each finding with
  its first repair and exits 1 on findings, so it can gate a build.
- `import { checkPage } from "nodality/check"`.
- `base` (option, flag and MCP parameter): the origin a prerendered page is
  served from. Its fonts, stylesheet and bundle are named by absolute path, and
  without a base the page was measured in a fallback face — clipping and
  overflow findings described a page no visitor sees.

The skill says so under "Verifying your work".
