# v1.3.19 — draft

> Draft only. Edit freely and paste into the GitHub release; nothing here is published.

Five fixes from building a real page with the raster ops and the shop
elements, each one a thing that cost an agent a debugging round.

## Live HTML-in-Canvas no longer gives up in a background tab

The live backend falls back to the snapshot when no paint event arrives within
1500ms. A hidden document paints nothing at all, so a page opened in a
background tab was sent to the snapshot for good — in a browser that has
`texElementImage2D`. The clock now starts when the page is first shown.

## An image keeps a dimension you declared

`Image.width()` and `Image.height()` each reset the other to `auto`, so an
image given one keeps its ratio. `resprop` calls those methods, so an image
with `width: "100%"` (or a keySet width) and a responsive height shrank to its
intrinsic ratio, silently. A width or height the page declared — as an option,
a keySet entry or the method — is now kept; an image given only one still
keeps its ratio.

## `INERT_RASTER_OP`: an op that cannot draw is reported

`edges` colours the cell borders a cell-stage op writes; alone, or after the
cell op on a different element, it validated clean and drew nothing. Ops can
now declare what must come before them (`needs: "cell"` on `edges`), and
`validate_nodes` warns when it does not, naming the ops that would feed it.

## `LOADING_LAYOUT_SHIFT` in `check_page`

A shop product shows a static copy until the shop answers. `check_page` now
blocks the shop script (so a product is checked in the state every visitor
sees first, without a store), stamps the template the way Shopify does,
measures every live element against its static copy and reports a difference
over 8px. It catches the 1.3.17 placeholder bug that 1.3.18 fixed, which no
earlier check could see because nothing overflowed.

## `describeOps()` says what shows at rest

- `driverDocs`: one line per driver, including whether anything is visible
  before anyone interacts (`hover`: nothing at rest or on a phone; `mouse`:
  stays on where the pointer last was). `drivers` is unchanged.
- `hexalize`'s summary says a lifted chain is pixel-identical away from the
  focus — so `by: "hover"` is flush at rest.
- Ops carry `needs` where they declare it.
- The raster module's header no longer says web fonts never reach the
  snapshot: they are embedded, and have been for a while.

Tests: 4 new test files (14 tests), each run against the previous code first
to see it fail.
